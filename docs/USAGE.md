# Usage / 使用指南

Choose a prompt matching your task, fill every variable, and provide relevant context. If an input is unavailable, say so explicitly. Ask the model to separate facts, assumptions, and verification steps.

For code, use a small fixture first, inspect file operations, record the environment, and compare observed outputs with the acceptance checks. For literature tasks, verify references against primary sources. Save useful failures as evaluation cases.
