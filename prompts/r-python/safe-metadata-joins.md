# 安全合并表达数据与样本信息

## Purpose / 适用场景

用于安全合并表达数据与样本信息，交付可审查的方案或代码。输入不满足要求时应先澄清，不能把方案当作实际运行结果。

## Inputs / 输入参数

| Variable | Required | Meaning |
| --- | --- | --- |
| `{{tables}}` | Yes | 各表字段、样本/基因方向和小型示例 |
| `{{keys}}` | Yes | 连接键、唯一性、空值和预期关系基数 |
| `{{goal}}` | Yes | 保留样本集合、顺序与允许缺失的规则 |
| `{{environment}}` | Yes | R/dplyr 或 Python/pandas 及版本 |

## Example / 使用示例

以下为合成情景，用于替换所有参数，不代表真实研究或模型测试：

- `{{tables}}`：合成：左表 sample_id=['001','002']；右表 sample_id=[1,2]，group=['A','B']。

## Acceptance checks / 验收标准

- 识别前导零与类型问题，先确认是否确为同一 ID 系统。
- 不靠自动数值转换默默合并。
- 确认映射后检查唯一性、集合及顺序。
- 删除任一必填输入时应提出具体澄清问题，而不是补造输入。
- 示例中的异常必须被报告；没有运行证据时不得写成已执行。

## Limitations / 局限

映射是否正确需要数据所有者确认，代码无法推断 ID 的真实语义。
